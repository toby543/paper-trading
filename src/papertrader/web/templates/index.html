from config.yaml
Account
Starting capital₹{{ account.get('starting_capital', 0)|inr }}

Ledger file{{ account.get('state_file', '—') }}
SQLite file holding cash, open positions, and the full trade history.
Universe
Symbol list{{ universe_cfg.get('file', '—') }}
CSV of NSE symbols scanned every cycle. Edit this file to change which stocks are considered — no code changes needed.
Execution realism
Slippage{{ execution.get('slippage_bps', '—') }} bps
Simulated fills are nudged against you by this many basis points, so paper P&L isn't unrealistically better than a real fill would be.
Flat charges₹{{ execution.get('flat_charges_inr', 0)|inr }} / order
Approximate brokerage + STT charged on every simulated buy and sell.
Market hours & scheduling
Session{{ engine_cfg.get('market_open', '—') }}–{{ engine_cfg.get('market_close', '—') }} {{ engine_cfg.get('timezone', '') }}
NSE trading window the engine treats as "market open" — it idles outside these hours and on holidays.
Entry scan intervalevery {{ engine_cfg.get('scan_interval_minutes', '—') }} min
How often the full universe is re-scanned for new 52-week-high momentum candidates.
Exit check intervalevery {{ engine_cfg.get('exit_check_interval_minutes', '—') }} min
How often open positions are rechecked for stop-loss / trailing-stop / momentum-breakdown — kept more frequent than entry scans.
Holiday calendar{{ engine_cfg.get('holidays_file', '—') }}
NSE trading holidays the engine treats as market-closed, in addition to weekends.
Data source
Preferred / fallback{{ data_source.get('preferred', '—')|upper }} → {{ data_source.get('fallback', '—')|upper }}
NSE's own site is tried first for genuinely live quotes; Yahoo Finance (delayed) is used automatically if NSE is unreachable or blocks the request.
Request timeout / retries{{ data_source.get('request_timeout_seconds', '—') }}s / {{ data_source.get('max_retries', '—') }}
How long a single price request waits before giving up, and how many attempts before falling back.
Logging
Log file / level{{ logging_cfg.get('file', '—') }} ({{ logging_cfg.get('level', '—') }})
Where scan activity, buys/sells, and warnings get written. Set to DEBUG for more detail while troubleshooting.
